# flow.loop — 循环

本分类用 EXEC 驱动「重复执行」：**For Each** 按列表项次数跑，**While** 按条件跑到结束或达上限。

| 节点 | 教程 | 一句话 |
|---|---|---|
| For Each Loop | [for_each.md](./for_each.md) | 列表每项一次 Exec Body，再 Complete |
| While Loop | [while.md](./while.md) | Condition 为真则 Body，假或达上限则 Complete |

常与 [`flow/control`](../control/) 的 Manual Trigger、Branch、Do Once 搭配。进度见 [PROGRESS.md](../../PROGRESS.md)。
