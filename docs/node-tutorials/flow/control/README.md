# flow.control — 流程控制

本分类负责 **EXEC 执行流** 的分流、顺序、闸门与手动触发，是带副作用图（预览提交、世界写入）的入口层。

| 节点 | 教程 | 一句话 |
|---|---|---|
| Branch | [branch.md](./branch.md) | 按布尔条件走 True / False |
| Sequence | [sequence.md](./sequence.md) | 按顺序触发最多 8 步 EXEC |
| Do Once | [do_once.md](./do_once.md) | 同一次 run 只放行一次 |
| Manual Trigger | [manual_trigger.md](./manual_trigger.md) | 按钮触发一次性 EXEC |

进度见 [PROGRESS.md](../../PROGRESS.md)。
