| 节点 | 教程 | 一句话 |
|---|---|---|
| Text Input | [text_input.md](./text_input.md) | 多行文本 |
| Color Picker | [color_picker.md](./color_picker.md) | RGBA 颜色 |
| Boolean Toggle | [boolean_toggle.md](./boolean_toggle.md) | 开关 |
| Gradient Ramp | [gradient_ramp.md](./gradient_ramp.md) | 多色标渐变采样 |
| Value List | [dropdown.md](./dropdown.md) | 从字符串选项里选一项 |
| File Path Input | [file_path.md](./file_path.md) | 本地文件路径 |

进度见 [PROGRESS.md](../../PROGRESS.md)。
